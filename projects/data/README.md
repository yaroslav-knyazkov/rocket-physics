# projects/data/ — личные данные пользователя

Эта папка — **ваши собственные** данные: реальные кривые тяги моторов,
реальные зондирования атмосферы и т.п. Она в `.gitignore` (кроме этого
файла) и никогда не попадёт в коммит — в отличие от `projects/examples/data/`,
которая хранит bundled-фикстуры проекта (демо-моторы, демо-зондирования),
читаемые тестами и примерами, и которая тоже версионируется.

## Как раскладывать

Любая подструктура — на ваш вкус, например:

```
projects/data/
  motors/<campaign>/<motor>.eng
  soundings/<case>/<station>.csv
```

Ничего из этого проект не создаёт и не ждёт по умолчанию — положите файлы
сюда сами.

## Как сослаться на файл отсюда

`sim.datafiles.resolve()` различает два случая по форме имени:

- **Голое имя файла** (без разделителя пути, например `"placeholder.csv"`)
  — всегда резолвится в bundled-корпус `projects/examples/data/<kind>/`, НЕ в
  эту папку. Так работают все демо- и тестовые фикстуры проекта.
- **Явный относительный путь** (с разделителем, например
  `"projects/data/motors/cspace/foo.eng"`) — резолвится относительно
  текущей рабочей директории (`cwd` в момент вызова, правило 2 резолвера).
  Именно так указываются файлы из этой папки.

Пример в конфиге сценария:

```python
Motor(
    name="my_real_motor",
    thrust=Thrust(motor_curve="projects/data/motors/cspace/my_motor.eng"),
)
```

Главное отличие от bundled-фикстур: **голым именем сюда не попасть** —
бестире имя всегда уходит в `projects/examples/data/`. Если хотите использовать
свой файл, путь к нему должен содержать хотя бы один разделитель (`/`
или `\`), иначе резолвер решит, что это одна из фикстур проекта.
