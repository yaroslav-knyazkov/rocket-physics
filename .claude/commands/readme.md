Задача: аудит README.md, только audit-режим, никаких правок.

1. Определи текущую ветку и базовую (`main`, при отсутствии — `master`).
2. Получи список изменённых файлов: `git diff --name-only main...HEAD` (или `master...HEAD`, если `main` нет).
3. Если список пуст — сообщи об этом пользователю и не вызывай агента.
4. Иначе вызови субагента **readme-keeper** (Agent-тул) в **audit**-режиме со скоупом = этот список файлов + README.md. Передай ему точный список файлов и попроси ограничить аудит секциями README, которые касаются этих файлов (см. правило «Скоуп аудита» в его системном промпте) — не весь README, если явно не попросили иначе.
5. Дождись ответа, покажи пользователю отчёт (таблицу расхождений и блок «Требует решения человека») как есть, без пересказа.
6. Если отчёт содержит предлагаемые правки — не применяй их. Apply-режим только по отдельному явному запросу пользователя после того, как он увидит и подтвердит список изменений.
